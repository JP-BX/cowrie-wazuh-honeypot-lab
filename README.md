# SSH Honeypot Threat Detection & Monitoring with Cowrie and Wazuh

SSH honeypot lab using Cowrie and Wazuh SIEM to capture, centralize, and analyze simulated attacker activity.

## Project Overview

In this project, I built and configured an SSH honeypot using Cowrie and integrated it with Wazuh for centralized security monitoring and analysis.

The goal was to simulate SSH-based attacker activity, capture commands and session data generated by the honeypot, and forward the telemetry to a Wazuh server where the events could be indexed, searched, and analyzed.

Rather than using a preconfigured honeypot platform, I manually configured the Cowrie and Wazuh integration. This included deploying the honeypot, configuring the Wazuh agent, forwarding Cowrie JSON logs, enabling archive indexing with Filebeat, and validating the complete event pipeline in the Wazuh Dashboard.
